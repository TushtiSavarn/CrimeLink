# 🚨 CrimeLink – Online Crime Reporting System

**CrimeLink** is a web-based crime reporting platform built with PHP and MySQL. It allows citizens to securely report crimes, upload evidence, send emergency SOS alerts, and track case statuses — while police and admin users manage reports and investigations efficiently.

---

## 📸 Features
- Secure User Authentication (Citizens, Police, Admins)
- Online Crime Reporting with evidence upload
- Emergency SOS with real-time location alert
- Real-time Case Tracking Dashboard
- Role-based access control
- Chatbot Integration 
- Admin Analytics Panel

---

## 🛠️ Built With
- PHP (Backend)
- MySQL (Database)
- HTML, CSS, JavaScript (Frontend)
- XAMPP / phpMyAdmin (for local hosting)

## 📦 Installation

- Clone the repo:
 
- Set Up the Database

- Open phpMyAdmin via XAMPP or your local server.

- Create a new database named crimelink.

- Import the crimelink.sql file provided in the repository to create the required tables (user1, report, status, etc.).

- Configure the Environment

- Place the project folder inside htdocs/ (if using XAMPP).

- Start Apache and MySQL from the XAMPP Control Panel.

- Open the project in your browser:

- Set Database Credentials

- Open your PHP files (like db.php, form.php, etc.)

- Set your MySQL connection .
